# Tarjan SCC Condensation Component Graph Counter (`scc_condensation_d59`)

> Category: **Directed Graphs** | Language: **C++20**

## Overview

Decomposes directed graphs via recursive DFS lowlink stacks into SCC equivalence classes and returns component count and DAG condensation edges.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Strongly connected cycles condense into exactly one node with zero self-loops.
