# Linear Monotonic-Stack Cartesian Min-Heap Tree (`cartesian_min_tree_d57`)

> Category: **Randomized & Treap Trees** | Language: **C++20**

## Overview

Constructs the unique binary Cartesian tree satisfying both array inorder equivalence and parent <= children min-heap property in a single O(N) pass.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Inorder traversal reconstructs the original slice exactly while obeying min-heap inequalities.
