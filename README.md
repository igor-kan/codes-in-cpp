# Modern C++20 Scientific Computing

Modular, concept-constrained C++20 implementations of computational linear algebra, Runge-Kutta ODE solvers, quaternions, and numerical recipes.

## Core Algorithm Suite

The repository also ships self-testing C++20 implementations across
`data_structures/`, `numerical/`, `sorting/`, `strings/`, `techniques/`,
`greedy/`, `geometry/`, `searching/`, `selection/`, `randomized/`, and
`advanced_data_structures/`. Every algorithm compiles with `g++ -std=c++20`
and is exercised by a `test_<name>.cpp` wrapper.
